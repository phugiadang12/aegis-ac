# dashboard

TypeScript + React UI for the SOC workflow: the alert queue, case reports (likely cheat
type, skill check, review checklist), a 2D replay of the suspect's aim, and ban waves.

```powershell
npm install
npm run dev          # http://localhost:5173, talks to the SOC API on port 8008
```

Today it runs on simulated matches (**Inject cheater**). Live real matches are next on
the [roadmap](../docs/ROADMAP.md).
